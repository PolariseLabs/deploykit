# @deploykit/core

Provider-independent deployment contracts and the shared `Deploykit` Effect service.
Includes artifacts, manifests, typed failures, transfer budgets and telemetry.
Use a provider adapter to deploy; composition and application verification stay in your app.

Alpha API, version `0.1.0-alpha.1`. Node 22.19 or newer.
Effect integrations use exactly `effect@4.0.0-rc.112`; keep the runtime graph aligned.
