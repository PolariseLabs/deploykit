# @deploykit/devtools

Local deployment telemetry and debugging for deploykit. Collect progress, timing
and failure events without coupling deployments to a telemetry vendor. Run beside
your deployment process; application checks and hosted monitoring stay in your app.

Alpha API, version `0.1.0-alpha.1`. Node 22.19 or newer.
Effect integrations use exactly `effect@4.0.0-rc.112`; keep the runtime graph aligned.
